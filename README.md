# 多个 Excel 合并成一个表（命令行工具）

把一堆结构相同的 `.xlsx` / `.xlsm` 纵向合并成一个总表，**自动加「来源文件」列**，只保留一份表头。

## 什么时候用它，什么时候用 Excel 自带功能

| 场景 | 更合适 |
|---|---|
| 几个表、想汇总求和 | Excel「数据 → 合并计算」（免费自带） |
| 结构一致、要动态刷新 | Power Query / VSTACK 函数（免费自带） |
| **几十上百个文件、跨文件夹** | **本工具** |
| **想保留每行数据来自哪个文件** | **本工具**（自动加来源列） |
| 表头顺序不一致、要对齐 | 本工具（按表头名对齐，不足留空） |

> 说明白：前两类需求 Excel 自带功能就能免费解决，别花钱。这个工具解决的是后面几类。

## 用法

```bash
python merge_excel.py <文件夹> -o 合并结果.xlsx
```

- 递归扫描文件夹下所有 `.xlsx`
- 自动跳过临时文件（`~$` 开头）
- 按表头名对齐列；某文件缺列则留空
- 输出多一列「来源文件」，方便回溯

依赖：`openpyxl`
